# 智能成绩录入

面向教师的微信小程序：拍摄或上传手写成绩表，经视觉模型识别后人工核对，保存到微信云数据库，并按日期查询、预览、导出 Excel。

## 部署

1. 使用微信开发者工具导入仓库根目录，开通云开发并选择云环境。`project.config.json` 中的 `appid` 是模板项目原值；正式使用时请改为自己的小程序 AppID。
2. 在 `miniprogram/app.js` 的 `globalData.env` 中填写云环境 ID。若项目已设置默认云环境，也可留空使用默认环境。
3. 在云开发数据库中建立集合 `classes`、`users`、`settings`、`scoreRecords` 和 `scoreMappings`。建议将这五个集合的前端访问权限设为**不可读写**；所有读写均通过云函数进行。为 `scoreRecords` 建立 `classId + date` 组合索引，为 `scoreMappings` 建立 `classId + rawText + _id` 组合索引，以提高查询速度。
4. 在开发者工具中右键 `cloudfunctions/gradeService`，选择“上传并部署：云端安装依赖”。云函数运行时使用 Node.js 16 或更新版本。
5. 在该云函数的环境变量中配置：

   - `AI_API_URL`：AI 服务根地址，例如 `https://ai.example.com`。不要填写 `/v1/chat/completions`；云函数会自动拼接该路径。
   - `AI_API_KEY`：该服务的 API Key，只配置在云函数中。
   - `AI_MODEL`：该服务中支持图片输入的模型名称。

   当前班级管理入口暂时隐藏，云函数默认把所有用户加入名称为 `一班` 的班级。需要重新启用首次选班、顶部班级显示和设置页切换时，将 `ENABLE_CLASS_MANAGEMENT` 设为 `true` 并重新部署云函数；不设置或设为其他值时保持隐藏。

   云函数使用 HTTPS POST 向 `AI_API_URL/v1/chat/completions` 发送图片的 base64 数据，不会直接请求 OpenAI 官方地址，API Key 也不会进入小程序代码。保存环境变量后重新部署 `gradeService`；请确认云函数运行环境能访问该服务域名，并将云函数超时时间设为至少 60 秒。未配置 AI 时仍可手动录入成绩。

6. 在开发者工具中编译并用真机测试拍照、云存储、识别、查询及文件分享。

## 数据结构

- `classes`：管理员在云开发控制台创建班级。每条记录使用稳定的英文、数字、下划线或短横线 `_id`（1–64 字符），填写显示名称 `name` 和数字 `order`（越小越靠前）；可选 `active: false` 用于停止新用户选择该班级。相同 `order` 按班级名称排序，未填写 `order` 的班级排在最后。例：`{ "_id": "class_2026_01", "name": "2026级一班", "order": 1 }`。
- `users`：用户首次确认班级时由云函数创建，`_id` 为当前微信用户在此小程序中的 OpenID，`classId` 为已授权班级 ID 数组，例如 `["class_2026_01", "class_2026_02"]`，另有 `createTime`、`updateTime`。用户可在“设置”页查看和复制自己的用户 ID，也可在已授权班级之间切换。首次绑定后如需增减可访问的班级，由管理员修改数据库中的数组。
- `settings`：每班一条，`_id` 与 `classId` 均为班级 ID，另含 `classSize`、`subjects`（科目名称数组）、`updateTime`。首次保存设置时自动创建；此前该班默认人数 30、科目列表为空。
- `scoreRecords`：每条成绩记录包含 `classId`、`createdByOpenId`、`date`、`subject`、`content`、`scores`、`imageFileID`、`createTime`、`updateTime`。`scores` 为 `{ studentNo: "01", score: 95 }` 数组；AI 返回的 `rawText` 不入库。查询与导出只使用当前选中班级的记录。
- `scoreMappings`：每条记录保存同一班级中一组 `rawText` 与数字 `score` 的对应关系，含 `classId`、`rawText`、`score`、`count`、`createTime`、`updateTime`；`_id` 由这三个对应字段生成。同一原始文本可对应多个分数。识别时选该班出现次数最多的分数；次数相同则选较小的分数。只有带识别图片并最终保存的成绩才会累计次数；无历史对应关系时成绩留空，需教师填写。原始文本仍不存入 `scoreRecords`。
- 图片上传到云存储 `score-sheets/<班级ID>/`；导出的 Excel 保存在 `成绩导出/<班级ID>/<月份或月份范围>/`，文件名包含成绩起止日期和北京时间导出时刻。末尾短码用于避免重名。本地保存和分享沿用同一文件名。

同班用户共同读取和修改该班的设置及成绩。班级管理关闭时，云函数按 `classes.name = "一班"` 查找唯一且未停用的班级，自动把其 ID 加入 `users.classId` 数组，并强制所有读写使用它；其他已授权班级和历史成绩仍保留。重新开启班级管理时，当前班级 ID 从小程序本地读取，云函数核对它是否在 `users.classId` 数组中。单次查询最多 300 条成绩表记录；超过时会提示缩小日期范围。

当前没有教师白名单或角色权限；若小程序对公众开放，任何新用户都能选择一个或多个可选班级并读写这些班的数据。管理员应控制小程序使用范围及 `classes` 中开放的班级。同时修改同一班设置时，以最后一次保存的内容为准。

## 初始化云数据库

重新部署 `gradeService` 云函数并编译小程序。在云开发控制台准备五个集合：`classes`、`users`、`settings`、`scoreRecords`、`scoreMappings`。当前模式下，请在 `classes` 中保留唯一一条 `name` 为 `一班` 且未停用的记录；云函数使用它的 `_id` 关联设置和成绩，自动为新用户创建 `users` 文档并把已有用户加入该班。无需清除其他班级的数据。重新开启班级管理后，新用户会看到班级多选页；班级选择列表最多读取 500 条班级记录。

## 使用

当前所有用户直接进入“一班”，首次选班、顶部班级显示和班级切换暂时隐藏。“设置”页仍可保存班级人数和科目。科目列表保存在云端，可增删；删除科目不会修改历史成绩。在“录入”页拍照或选图后，可在原图上移动裁剪框、拖动四角自由调整范围，也可使用整张原图；确认后才会上传并识别。请校对日期、科目、自动回填的“内容”及每位学生成绩；这些字段均可人工修改，提交前必须填写完整。到“导出”页选日期并查询；预览与 Excel 会显示“内容”。每张查询结果卡片可展开，也可确认后永久删除该条成绩记录；删除不会清理此前上传的图片。确认导出后可在微信中预览 Excel、保存到小程序，或分享文件到微信聊天。预览页右上角菜单也可转存文件。
